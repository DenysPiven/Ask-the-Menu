# Що брати (корисна база)

Профіль: `denys-mediterranean-2024` — Середземноморська + корисна база.

Режим ширший: не лише ідеальні боули, а **будь-яка нормальна їжа** без фритюру/солодкого/алко.

У кожному закладі: **їсти** / **з обережністю** / **пити** (+ короткі приклади чого уникати).

> Не медична рекомендація. Голодний > ідеальний. При СПК — бульйон, рис, яйце.

Перегенерація: `python3 filter_diet_picks.py`
