# Дієта Denys — середземноморська + корисна база

Профіль для вибору їжі вдома й у закладах. База: рекомендація терапевта (*середземноморська дієта*, Status, 13.08.2024) + діагнози.  
У меню закладів режим **ширший**: беремо не лише «ідеальний» боул, а будь-яку нормальну їжу без фритюру, солодкого й алкоголю — щоб було що їсти.

**Вдома зараз:** ремонт, кухні/плити немає. Лише готові перекуси з Сільпо (відкрив і з’їв). Повноцінна їжа — у закладах, найближчий LongShot (просп. Юності, 18). Доставка Сільпо: просп. Юності, 75, кв. 62.

Це не заміна призначень лікаря.

## Для чого підганяємо

| Стан | Що важливо в їжі |
|---|---|
| Синдром Жільбера | Не голодувати довго; менше алкоголю й важкого жиру |
| Єдина ліва нирка / полікістоз | Помірний білок (~0,8–1,0 г/кг ≈ 58–72 г/день), мало солі, вода |
| Гіпотиреоз (компенсований) | L-тироксин натще; каву/сніданок — не одразу після таблетки |
| СПК | Регулярні порції; при загостренні — простіше |
| Кальцифікати в руках | На дієту напряму не впливають |

## Їсти (в т.ч. у закладах)

- риба й морепродукти: лосось, тунець, креветки (не у фритюрі)
- курка / індичка без паніровки: філе, стейк, шашлик, боул
- прості суші / макі без темпури
- салати, боули, овочі гриль **без томатів**
- яйця, омлет, тости з авокадо / лососем
- супи й бульйони без важких вершків
- рис, гречка, вівсянка, варена/печена картопля (у закладах; вдома зараз не готуємо)
- фунчоза / локшина з овочами й білком (без фритюру)
- вдома ready-to-eat: курка гриль, тунець у соку, грецький йогурт, творог, хумус, фрукти, огірок
- вода негазована, чай без цукру

## Точно не їсти

- фрі, нагетси, стріпси, крильця, темпура, кацу
- дабл-бургери, BBQ, кебаб, гірос
- бекон / салямі як основа
- карбонара, важкі вершкові соуси
- солодкі круасани, шейки, сиропи
- алкоголь, кола, sprite, енергетики, лимонади
- кава (не п’є)
- томати / чері
- чипси, жувальні цукерки
- довгі вікна без їжі

## Як їсти день

1. **Ранок:** L-тироксин → пауза → потім їжа (каву не п’є).
2. **3 прийоми** (+ легкий перекус, якщо перерва >4–5 год).
3. **Не залишайся голодним** — краще «норм» страва, ніж нічого.
4. **Сіль:** не досолюй.
5. **Загострення СПК:** бульйон, рис, банан, яйце, біла риба, чай.
