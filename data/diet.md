# Дієта Denys — за діагнозами

Профіль для дому й закладів. **Без** середземноморської дієти від лікаря — лише діагнози + що сам не їси/не п’єш.

**Вдома зараз:** ремонт, плити немає → готові перекуси з Сільпо. Повноцінно — у закладах (LongShot тощо). Доставка: просп. Юності, 75, кв. 62.

## Діагнози → їжа

| Стан | Що з цього для їжі |
|---|---|
| Синдром Жільбера | Не голодуй довго; алкоголь і важкий жир — рідко |
| Єдина ліва нирка / полікістоз | Білок помірно (~58–72 г/день), не досолюй, пий воду |
| Гіпотиреоз (компенсований) | L-тироксин натще → їжа через 30–60 хв |
| СПК | Якщо погано — простіше (бульйон, рис, банан, яйце). Якщо норм — звичайна їжа |
| Кальцифікати в руках | На їжу не впливає |
| Міопія −7, корекція (2022) | На їжу не впливає |
| Тендовагініт / меніски | На їжу майже не впливає |

## Особисте

- Каву й алкоголь не п’є
- Томати не любить
- Голодний > «ідеальний»

## Нормально їсти

- курка, індичка, риба, яйця
- супи (борщ, бульйон; солянка — не щодня)
- гречка, рис, пюре, овочі
- салати **без томатів**
- млинці/налисники — ок інколи (краще не солодка гора)

## Краще рідко / з обережністю

- дуже солоне, копчене, крабовий з майонезом
- фрі, нагетси, бургери щодня
- важкі вершкові соуси, якщо відчуваєш важкість

## Не брати

- алкоголь, кава
- томати
- довгі паузи без їжі
