# Дієта Denys — середземноморська (адаптована)

Профіль для вибору їжі вдома й у закладах. База: рекомендація терапевта (*середземноморська дієта*, Status, 13.08.2024) + твої діагнози.  
Це не заміна призначень лікаря й не індивідуальний план нефролога/ендокринолога.

## Для чого підганяємо

| Стан | Що важливо в їжі |
|---|---|
| Синдром Жільбера | Не голодувати довго; не сідати на жорсткі низькокалорійні дієти; менше алкоголю й важкого жиру |
| Єдина ліва нирка / полікістоз | Помірний білок (~0,8–1,0 г/кг ≈ 58–72 г/день), мало солі, пити воду |
| Гіпотиреоз (компенсований) | Стабільний режим; L-тироксин натще; каву/сніданок — не одразу після таблетки |
| СПК | Регулярні порції; при загостренні — простіше, менше сирих овочів, бобових, гострого, газів |

## Їсти

- риба й морепродукти: лосось, тунець, креветки (не у фритюрі)
- курка / індичка без паніровки
- салати й боули з оливковою олією
- авокадо, яйця, овочі (огірок, томати, листя)
- вівсянка, рис, варена картопля
- грецький йогурт без цукру (якщо кишківник ок)
- горіхи / хумус — маленькими порціями при ремісії
- вода, чай, американо / еспресо без сиропу

## Точно не їсти

- фрі, нагетси, стріпси, крильця, цибулеві кільця
- дабл-бургери, BBQ, кебаб, гірос
- ковбаси / бекон / салямі / солоні м’ясні дошки
- вершкові пасти, карбонара, сирники з карамеллю
- солодкі круасани, шейки, десерти з сиропом
- алкогольні сети й шоти
- кола, енергетики, солодкі лимонади
- довгі вікна без їжі й «детокс» на дуже низьких калоріях

## Як їсти день

1. **Ранок:** L-тироксин → пауза → потім їжа/кава.  
2. **3 прийоми** (+ легкий перекус, якщо перерва >4–5 год).  
3. **Порція білка** на прийом помірна (не стейк + протеїновий шейк + ще сир).  
4. **Сіль:** не досолюй; уникай готових солоних снеків.  
5. **При загостренні СПК:** бульйон, рис, банан, яйце, біла риба, чай; без сирої цибулі/часнику, бобових, газівки й гострого.

## У закладах (коротко)

1. Салат / боул з рибою або куркою.  
2. Лосось / креветки / тунець без важкого соусу.  
3. Напій: вода / чай / американо.
